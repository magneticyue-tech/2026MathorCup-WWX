# Memory index

Segmented project memory. One fact per file in this folder, each with
frontmatter (see `_TEMPLATE.md`). This index lists every memory file with a
one-line hook. Add a line here whenever you add a file; do not put memory
content in this index.

Memory holds only facts not recorded elsewhere: project decisions and their
rationale, fixed constraints, and external references. It does not restate
rules that live in `COLLABORATION.md` or a `.claude/skills/` file — those are
authoritative there, and a copy here only drifts. If a fact would be edited in
COLLABORATION or a skill when it changes, it belongs there, not here.

Categories (via the `type` frontmatter field):
- `decision` — a modeling/coding/writing choice and why it was made
- `constraint` — a fixed requirement (data source, deadline, plan limit)
- `reference` — external resource (link, ticket, dataset origin)
