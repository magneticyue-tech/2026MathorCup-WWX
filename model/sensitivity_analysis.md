## Notes
- State the seed used for any stochastic run.
- Report effects as numbers or figure references, not adjectives.
- Mark rows awaiting a solver run `[PENDING]` with the work-order task or script
  that clears them.
- Sensitivity perturbs the fixed assumptions to assess robustness. It is
  distinct from out-of-sample validation, which belongs in the methodology
  document, and does not substitute for it.
