## 任务 2：`data.py`（重写）

常量：
- `DIMS`：附件 4 的 50 列，顺序与 `data/raw/4.csv` 第 4 列起一致，写成字面量列表。
- `DIM_GROUPS`：字典，6 个键 `Aroma`（15 个 `A_` 开头）、`Flavour`（15 个 `F_` 开头）、`Defect`（dms、metallic、X4vg、t2n、diacetyl、stale_hops）、`Spice`（orange、coriander、clove）、`Sour`（lactic、acetic、barnyard）、`Basic`（body、alcohol、bitternes、sweetness、co2、acidity、aftertaste、overall）。模块加载时断言 6 组互不相交且并集恰为 `DIMS`。
- `ZERO_HEAVY_DIMS`：22 个维度，写成字面量：A_malt_burn、A_hops_citrus、A_hops_tropical、A_hops_woody、A_esters_flower、F_malt_burn、F_hops_citrus、F_hops_tropical、F_hops_woody、F_esters_flower、acidity、X4vg、diacetyl、metallic、stale_hops、t2n、orange、coriander、clove、lactic、acetic、barnyard。测试中断言它等于「G 中零级占比 ≥ 0.5 的维度」。
- `NA_COLS`：附件 1 中含 NA 的 9 列，写成字面量：X2.3.butanedione、X3.methylbutanal、ethyl.isobutyrate、methylpyrazine、furfural、amyl.acetate、phenylacetaldehyde、ethyl.nicotinate、aroma_hops_sum。`SUM_NA_COL = 'aroma_hops_sum'`。
- `FLOOR_VALUE = -1.81781854`。

函数：
- `grade(v)`：`np.floor(np.clip(v, 0, 6) + 0.5).astype(int)`。
- `load_raw_ratings(path=RAW_SENSORY) -> DataFrame`：`encoding='cp1252'`；把 `A_ester_fruity`、`F_ester_fruity` 更名为 `A_esters_fruity`、`F_esters_fruity`；把 `beer_name` 更名为 `row`；`DIMS` 列转 float。断言：2,197 行；`row` 取值恰为 1–250；16 名品评员（`taster`）；37 个日期（`date`）；`DIMS` 列无缺失且取值属于 {0,…,6}。
- `date_groups(ratings) -> ndarray`：长度 250，下标为 `row-1`。对日期做并查集：同一 `row` 出现在多个日期时，把这些日期并为一组；每款啤酒取其日期所在的组。组标号按组内最小 `row` 升序重新编号为 0..24，保证结果确定。
- `panel_targets(ratings) -> Q1Targets`：dataclass，字段 `xbar`（250×50，按 `row` 升序对每个 `DIMS` 列求均值）、`G`（250×50 int，`grade(xbar)`）、`n_ratings`（250）、`date_group`（250）。
- `additive_effects(ratings, rows, dims=DIMS, n_iter=500, tol=1e-8) -> tuple[DataFrame, DataFrame]`：移植 `experimentalCode/q1_raw_target/rawlib.py` 的 `additive`，收敛条件改为 `max|Δalpha| < tol` 或 500 轮。算法：只用 `rows` 中啤酒的评分；`bi, ub = pd.factorize(sub['row'])`，`pi, up = pd.factorize(sub['taster'])`；循环内对每个维度 j 先 `alpha[:, j] = bincount(bi, X[:, j] - beta[pi, j]) / cb`，再 `beta[:, j] = bincount(pi, X[:, j] - alpha[bi, j]) / cp`；每轮末令 `m = (beta * cp[:, None]).sum(0) / cp.sum()`，`beta -= m`，`alpha += m`。返回 `alpha`（行索引 `ub`，列为维度）和 `beta`（行索引 `up`）。
- `load_q1() -> Q1Data`：读 `RAW_DIR/1.csv`、`4.csv`；`X` 为 1.csv 中除 `beer`、`beer_id`、`tasting_category_fine` 以外的 231 列（float）；`Z` 为 4.csv 的 `DIMS` 列；`beer` 为 4.csv 的 `beer` 列；`style` 为 `tasting_category_fine`；`targets = panel_targets(load_raw_ratings())`。断言：`X.shape == (250, 231)`；两表 `beer` 列逐行相同；`Z` 的列名等于 `DIMS`；按行号对齐时原始均分与 `Z` 的逐维 Spearman 中位数 ≥ 0.95，按 `beer` 列对齐时 ≤ 0.1。`load_q1` 不得做折半、重建等耗时核对。

`ChemNAEncoder(scheme)`，`fit(X_train) -> self`，`transform(X) -> DataFrame`（只返回一个表，指示列并入该表；旧版的元组返回取消，所有调用处同步改）。四种方案：
- `col_mean`（主设定）：`fit` 记录训练折列均值（NaN 不计）；`transform` 用它填充；不加指示列。训练折某列全为 NaN 时 `raise ValueError`。
- `median_ind`（对照 a）：用训练折列中位数填充；对 `NA_COLS` 的 9 列各加一列 `<列名>_missing`（0/1）。
- `native_nan`（对照 b）：不填充，不加指示列。
- `floor_ind`（对照 c）：8 个单化合物列（`NA_COLS` 去掉 `aroma_hops_sum`）的 NaN 改为该列训练折最小值，并各加 `<列名>_missing`；`aroma_hops_sum` 保持 NaN。
- 未知 `scheme` 抛 `ValueError`。旧的 `main`（填 0）方案删除。
- `floor_indicators(X) -> DataFrame`：对含 `round(x, 8) == FLOOR_VALUE` 单元的列，生成 `<列名>_floor`（0/1）；只供 W4 的线性对照使用。

数据核对函数（只读，供 `solve_q1_data.py` 调用；算法对应 `q1_raw_data_checks.py` 的同名检查块）：
- `check_id_mapping(ratings, xbar, a4) -> dict`（检查 A）：返回按行号与按 `beer` 列对齐的逐维 Spearman 中位数，以及 250×250 轮廓相关矩阵（逐行去均值后余弦）经 `scipy.optimize.linear_sum_assignment(-C)` 得到的指派中等于行号的款数。
- `reconstruct_attachment4(ratings, a4) -> ndarray[bool]`（检查 B、C）：对每名品评员、每个维度，用该品评员全部评分的均值和样本标准差（ddof=1）标准化；对每款啤酒取均值得到 250×50；`ok = |重建值 - a4| < 1e-6`（NaN 视为不一致）。另返回恒为同一数值（标准差为 0）的「品评员 × 维度」组合个数及其所在维度数。
- `split_half_reliability(ratings, n_splits=20, seed=SEED) -> dict`（检查 G）：`rng = np.random.default_rng(seed)`；每次划分对 `ratings.groupby('row').groups.items()` 逐款执行 `idx = rng.permutation(np.asarray(idx))`，前 `len(idx)//2` 条为一半、其余为另一半；两半各自求每款均值，逐维求 250 款上的 Pearson 相关 $r$，Spearman–Brown 为 $2r/(1+r)$；20 次取平均得 `reliability`（50）。同时每次计算两半等级的完全一致率和二次加权 kappa（`labels=range(7)`，kappa 无定义的维度跳过），返回 `half_grade_exact`、`half_grade_qwk`（两个标量，对 20 次和 50 维取平均）。
- `attendance_share(ratings, xbar, dims=DIMS) -> ndarray`（检查 F）：`alpha` 取全部 250 款的 `additive_effects`，返回 `var(xbar - alpha) / var(xbar)`（逐维，ddof 相同）。
- `barnyard_check(ratings, xbar) -> dict`（检查 D）：barnyard 与 stale_hops 评分相同的记录占比、不同的记录数，以及啤酒均分的 Spearman。
- `panel_date_nesting(Z, date_group) -> dict`（检查 E）：用 `panels.infer_panels(Z, k=3)` 得到品评团，返回多啤酒组个数、覆盖啤酒数、跨越两个及以上日期组的品评团个数。
