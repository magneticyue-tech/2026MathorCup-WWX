## 固定规则

- 对外层折 (r, k)：训练行为 `fold_id[r] != k` 的行，测试行为 `fold_id[r] == k` 的行。
- 维度 d 的残差池只用 `inner_mu[r, k, 训练行, d]`（这些位置全部非 NaN，是内层折外预测）和 `xbar[训练行, d]`：`resid = xbar[训练行, d] - inner_mu[r, k, 训练行, d]`。
- 测试行的连续预测为 `oof_mu[r, 测试行, d]`。测试行的 x̄ 与 G 只在评价时使用，不进入 `apply_rules`。
- 训练行的等级为 `grade(xbar[训练行, d])`。

## 任务 1：`discretize.py`（重写）

- `grade(v)`：与 `data.grade` 完全相同的公式；两个模块各放一份时用测试断言二者相等，或在此处 `from .data import grade`（推荐，避免重复）。
- `qwk_score(y, yhat) -> float`：7×7 混淆矩阵 `o = np.bincount(7 * y + yhat, minlength=49).reshape(7, 7)`；`W[i, j] = (i - j) ** 2`；`e = np.outer(o.sum(1), o.sum(0)) / o.sum()`；分母 `(W * e).sum()` 为 0 时返回 `np.nan`，否则返回 `1 - (W * o).sum() / (W * e).sum()`。
- `predictive_dist(mu_te, resid, mu_ref=None, k=None) -> ndarray (n, 7)`：对每个测试预测值 μ，`g = grade(μ + resid)`，`p_c = 该值的等级为 c 的占比`。给出 `mu_ref`（与 `resid` 等长，是各残差对应的内层折外预测）和 `k` 时，对每个 μ 只用 `|mu_ref - μ|` 最小的 k 个残差：`np.argsort(np.abs(mu_ref - μ), kind='stable')[:k]`；距离相同时按下标靠前者，保证结果确定。`mu_ref`、`k` 必须同时给或同时不给，否则 `raise ValueError`。
- `dist_median(p) -> ndarray[int]`：`np.argmax(np.cumsum(p, axis=-1) >= 0.5 - 1e-12, axis=-1)`。
- `dist_interval(p, lo=0.05, hi=0.95) -> tuple[ndarray, ndarray]`：同样方法，阈值分别为 `lo - 1e-12`、`hi - 1e-12`。
- `const_mode(g_train) -> int`：`int(np.argmax(np.bincount(g_train, minlength=7)))`（出现次数相同时取较小等级）。
- `quantile_cuts(mu_inner, g_train) -> ndarray (6,)`：`cum = np.cumsum(np.bincount(g_train, minlength=7))[:-1] / len(g_train)`；`cuts = np.quantile(mu_inner, np.clip(cum, 0, 1))`（默认线性插值）；`cuts[cum >= 1 - 1e-12] = np.inf`。
- `apply_cuts(mu, cuts) -> ndarray[int]`：`np.searchsorted(cuts, mu, side='right')`。
- `qwk_cuts(mu_inner, g_train, n_pass=3) -> ndarray (6,)`：
  1. 初始 `c = np.arange(0.5, 6.0, 1.0)`（0.5, 1.5, …, 5.5）。
  2. `score(t) = np.nan_to_num(qwk_score(g_train, apply_cuts(mu_inner, t)), nan=-1.0)`；`best = score(c)`。
  3. 候选点 `grid = np.unique(mu_inner)`，再取 `grid[::max(1, len(grid) // 120)]`（与预运行 `fit_cuts` 一致，候选点个数约 120）。
  4. 重复 `n_pass` 遍：对 `i = 0..5`，`lo = c[i-1] if i > 0 else -inf`，`hi = c[i+1] if i < 5 else inf`；对 `grid` 中严格位于 `(lo, hi)` 内的每个 `v`：`t = c.copy(); t[i] = v`；`s = score(t)`；只有 `s > best` 时才更新 `c = t`、`best = s`。
  5. 返回 `c`。
- `apply_rules(mu_te, mu_inner, y_inner) -> dict`：令 `g_inner = grade(y_inner)`，`resid = y_inner - mu_inner`，返回：
  - `p = predictive_dist(mu_te, resid)`；`p_knn = predictive_dist(mu_te, resid, mu_inner, 50)`；
  - `const = np.full(n, const_mode(g_inner))`；`round = grade(mu_te)`；`median = dist_median(p)`；`quant = apply_cuts(mu_te, quantile_cuts(mu_inner, g_inner))`；`qwk_cut = apply_cuts(mu_te, qwk_cuts(mu_inner, g_inner))`；`median_knn = dist_median(p_knn)`。
  - 所有等级数组为 `int`，取值在 0..6。

## 任务 2：`code/scripts/solve_q1_scores.py`（重写）

- 参数 `--smoke`：读 `SMOKE_DIR/q1_main_oof.npz`，写 `SMOKE_DIR/q1_scores.npz`，只处理 npz 中已有的外层折（`fold_id` 与 `inner_mu` 非 NaN 的折）；正式运行读写 `PROCESSED_DIR`。
- 对每个 `r`、`k`、`d` 执行上述固定规则并调用 `apply_rules`，把结果写入对应测试行。运行前断言：对每个 `(r, k)`，`inner_mu[r, k]` 的非 NaN 行恰为训练行。
- 输出 `q1_scores.npz`：
  - 逐次重复：`p`（5, 250, 50, 7）、`p_knn`（5, 250, 50, 7）、`grade_const`、`grade_round`、`grade_median`、`grade_quant`、`grade_qwk_cut`、`grade_median_knn`（均为 (5, 250, 50)）；
  - 交付值：`p_final = p.mean(axis=0)`；`G_hat = dist_median(p_final)`；`lo, hi = dist_interval(p_final)`；`G_hat_Q = np.median(grade_quant, axis=0).astype(int)`（5 次取中位数，5 为奇数，结果为整数）；
  - 新啤酒与 Q3 用：`final_resid`（50, 1250），第 d 行为 `(xbar[:, d][None, :] - oof_mu[:, :, d]).ravel()`，即全部重复的折外残差；`final_qcuts`（50, 6），第 d 行为 `quantile_cuts(oof_mu[:, :, d].mean(axis=0), G[:, d])`；
  - `checks`（JSON 列表）、`seed`、`meta`。
- 脚本不画图，不读原始评分。

## 任务 3：`code/tests/test_q1_discretize.py`

手算用例（逐项断言）：
- `grade`：`[-0.2, 0.49, 0.5, 5.5, 6.4]` → `[0, 0, 1, 6, 6]`。
- `predictive_dist([2.0], [-0.6, 0.0, 0.6])` = `[[0, 1/3, 1/3, 1/3, 0, 0, 0]]`；`dist_median` = 2；`dist_interval` = `(1, 3)`。
- `predictive_dist([0.1], [-0.3, -0.2, 0.0, 0.4, 0.9])` 的 `p[0, 0] = 0.6`、`p[0, 1] = 0.4`，`dist_median` = 0。
- `predictive_dist([5.9], [0.5])`：`p[0, 6] = 1`。
- `const_mode([0, 0, 1, 1])` = 0（并列取较小）。
- `quantile_cuts(np.arange(6.0), np.array([0, 0, 0, 1, 1, 2]))`：前两个切点为 `[2.5, 4.1666667]`（误差 1e-6），后四个为 `inf`；`apply_cuts([2.4, 2.5, 4.2, 100], cuts)` = `[0, 1, 2, 2]`。
- `qwk_score`：完全一致时为 1.0；与 `sklearn.metrics.cohen_kappa_score(weights='quadratic', labels=range(7))` 在 20 组随机整数数组（种子 0）上相差不超过 1e-12；`y` 全为同一等级且 `yhat` 也全为同一等级时返回 NaN。
- 近邻：`mu_ref=[0.0, 0.1, 5.0]`、`resid=[1.0, 2.0, 3.0]`、`k=2`、`mu_te=[0.0]` 时选中的残差为前两个；`mu_ref` 与 `mu_te` 距离相同的两项，下标小的先入选（用 `mu_ref=[1.0, -1.0, 9.0]`、`mu_te=[0.0]`、`k=1`，选中第 0 项）。
- `qwk_cuts`：构造 `mu_inner` 为 0..6 的均匀随机数（种子 0，300 个）、`g_train = grade(mu_inner + N(0, 0.4))`；断言返回的切点严格递增，且 `qwk_score` 不低于从 0.5, 1.5, …, 5.5 出发的初始切点的得分。
- `apply_rules`：返回的所有等级数组取值在 0..6；`p` 与 `p_knn` 每行和为 1（误差 1e-12）。
- 无泄漏：对同一 `mu_inner`、`y_inner`，改变测试行的任何其他输入不影响结果（`apply_rules` 的签名只有 `mu_te`、`mu_inner`、`y_inner`，测试中断言函数签名参数个数为 3）。
