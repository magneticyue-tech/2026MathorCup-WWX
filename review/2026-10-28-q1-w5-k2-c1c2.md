## 问题

- 实现方法论 §5.3 的 K2、C1、C2 三个对照。
- 现有实现的错误：`ordinal.py` 没有令 $Q_0=1$，第 0 列恒为 0，累积最小值后整行为 0，输出的分布不成立，还把概率截断到 1e-9（`ordinal.py:7-23`）；`twostage.py` 的 C1 只是把 $\hat z$ 直接四舍五入，没有线性参照、局部零点和混合参照，C2 的 OLS 在训练折的拟合值上拟合（`twostage.py:5-25`）；`solve_q1_controls.py` 对 K2、C1、C2 只跑了第 0 次重复且没有嵌套选参（该脚本已在 W1 任务 0 中处理，不再使用）。
- 本工单依赖 W1（`ChemNAEncoder`、`DIMS`、`DIM_GROUPS`、`grade`、`load_q1`）、W2（`fit_outer_fold`、`merge_units`、`outer_splits`、`q1_main_oof.npz` 的 `chosen_params`、`fold_id`）和 W3（`apply_rules`、`qwk_cuts`、`quantile_cuts`、`dist_median`、`qwk_score`、`q1_scores.npz`）。
- 只创建或修改：`code/src/q1/ordinal.py`、`code/src/q1/twostage.py`、`code/scripts/solve_q1_ordinal.py`、`code/scripts/solve_q1_twostage.py`、`code/tests/test_q1_ordinal.py`、`code/tests/test_q1_twostage.py`。`panels.py` 不改，直接使用其 `infer_panels(Z, k=3)`。
- 运行环境与通用约定见本工单末尾「通用约定」。

## 任务 1：`ordinal.py`（K2，重写）

方法论 §5.3 K2：对 $t=1,\dots,6$ 拟合 $\mathbf 1\{G\ge t\}$，得到 $Q_t=\hat P(G\ge t)$；令 $Q_0=1$，沿 $t$ 取累积最小值，再差分得到 $p_k=Q_k-Q_{k+1}$（$Q_7=0$）。

- `cumulative_to_dist(q_raw) -> ndarray (n, 7)`：`q_raw` 形状 `(n, 6)`，第 `t-1` 列为 $Q_t$。先在最前面拼一列 1 得到 $Q_0..Q_6$（`(n, 7)`），`np.minimum.accumulate(..., axis=1)`，再在最后拼一列 0（$Q_7$），`p = Q[:, :-1] - Q[:, 1:]`。不得截断或加小量。
- `fit_predict_k2(X_tr, G_tr, X_te, params, cst, min_pos=2) -> tuple[ndarray (n_te, 7), ndarray (6,) bool]`：
  - `params` 为含 `max_depth`、`min_samples_leaf`、`learning_rate`、`l2_regularization`、`max_iter` 的字典（不含 `mono`）；`cst` 为 `None` 或与 `X_tr` 列数等长的整数列表。
  - 对 `t = 1..6`：`y = (G_tr >= t).astype(int)`；若 `min(y.sum(), len(y) - y.sum()) < min_pos`，该列取 `y.mean()`（所有测试行相同），对应标志为 True；否则 `HistGradientBoostingClassifier(loss='log_loss', early_stopping=False, random_state=SEED, monotonic_cst=cst, **params).fit(X_tr, y)`，该列取 `predict_proba(X_te)[:, 1]`。
  - 返回 `cumulative_to_dist(q_raw)` 和 6 个标志。
- `k2_fold(X_raw, xbar, dims, dim_groups, train_idx, test_idx, chosen) -> dict`：`chosen` 是该外层折在 6 个维度组上选定的参数 `{组名: best}`（`best` 含 `mono`，见 W2）。
  1. `tr = np.sort(train_idx)`，`te = np.sort(test_idx)`；`G_tr = grade(xbar[tr])`（只用训练行）。
  2. `enc = ChemNAEncoder('col_mean').fit(X_raw.iloc[tr])`，编码训练和测试行，转 float64 数组，`names` 为列名。
  3. 对每个维度 `d`：由 `dim_groups` 找到所属组，`best = chosen[组名]`，`cst = monotone_cst(names, d, best['mono'])`（`mono=False` 时全 0，可传 `None`），`params = {k: v for k, v in best.items() if k != 'mono'}`；调用 `fit_predict_k2`。
  4. 返回 `{'test_idx': te, 'p': (n_te, 50, 7), 'fallback': (50, 6)}`。
  - 超参数沿用主运行在该外层折、该维度组的选定值，不另做嵌套 CV（方法论 §5.3）。
- 删除旧的 `fit_predict_k2`。

## 任务 2：`twostage.py`（C1、C2，重写）

方法论 §5.3 的 C1：不读取任何原始评分，只用附件 4 的 $z$。算法参考 `experimentalCode/q1_raw_target/exp_twostage.py` 的 `group_zeros`、`local_scale`、`reference`、`fit_cuts`、`one_fold`，下面是逐步规定，不要照搬其全局变量写法。

常量：`NO_LOCAL = ('F_malt_all',)`；`C2_RULES = ('const', 'round', 'median', 'quant', 'qwk_cut', 'median_knn')`；`M_SCALE = 3.0`。

函数（`Z` 为 250×50 的 float64 数组，`panels` 为 `infer_panels(Z_df, k=3)` 的结果，`idx` 为排序后的行号数组）：

- `group_zeros(Z, panels, idx, dims) -> ndarray (250, 50)`：全 NaN 起步；对 `idx` 中出现的每个品评团 `g`，成员 `m = idx[panels[idx] == g]`；成员少于 2 个则跳过；`v = np.round(Z[m], 9)`，`mn = v.min(axis=0)`；对每个维度 `j`，若 `(v[:, j] == mn[j]).sum() >= 2` 且 `dims[j]` 不在 `NO_LOCAL`，则 `out[m, j] = mn[j]`。只用 `idx` 内的啤酒，`idx` 之外的行保持 NaN。
- `local_scale(zeros, panels, idx, m=M_SCALE) -> ndarray (50,)`：对每个维度 `j`：`ok = ~np.isnan(zeros[idx, j])`；没有有效值则为 NaN；否则每个品评团只计一次（`_, first = np.unique(panels[idx][ok], return_index=True)`，取 `zeros[idx, j][ok][first]`），`r = -np.median(这些值)`；`r > 0` 时 $\sigma^*=m r/(1+r^2)$，否则 NaN。
- `linear_endpoints(Z, idx) -> tuple[ndarray, ndarray]`：`Z[idx].min(axis=0)`、`Z[idx].max(axis=0)`。
- `linear_map(z, lo, hi) -> ndarray`：$6(z-\ell)/(u-\ell)$，对 `z` 的最后一维逐列广播。
- `mixed_reference(z, zb, sigma, lo, hi) -> tuple[ndarray int, ndarray bool]`：`z`、`zb` 同形状 `(n, 50)`；`L = grade(linear_map(z, lo, hi))`；`use = ~np.isnan(zb) & ~np.isnan(sigma)[None, :]`；`A = grade(np.where(use, sigma[None, :] * (z - zb), 0.0))`；返回 `np.where(use, A, L)` 与 `use`。不得对含 NaN 的数组调用 `grade`。
- `c1_fold(Z, xbar, panels, dims, train_idx, test_idx, oof_z, inner_z) -> dict`：`oof_z` 形状 `(n_te, 50)`、`inner_z` 形状 `(n_train, 50)` 是 z 模型的外层与内层折外预测（行顺序为排序后的 `test_idx`、`train_idx`），由 W2 的 `fit_outer_fold` 对目标 `Z` 得到。
  1. `tr`、`te` 排序；`lo, hi = linear_endpoints(Z, tr)`（只用训练行）。
  2. `zb_tr = group_zeros(Z, panels, tr, dims)`；`sigma = local_scale(zb_tr, panels, tr)`；`R_tr, _ = mixed_reference(Z[tr], zb_tr[tr], sigma, lo, hi)`。
  3. `zb_te = group_zeros(Z, panels, te, dims)`（只由测试啤酒计算）；`R_te, I_te = mixed_reference(Z[te], zb_te[te], sigma, lo, hi)`。`R_te` 只用于选型和参照误差，不参与任何预测。
  4. `Tp = linear_map(oof_z, lo, hi)`，`Ti = linear_map(inner_z, lo, hi)`。三个候选映射：
     - `round_T = grade(Tp)`；
     - `qwk_T`：对每个维度，`cuts = qwk_cuts(Ti[:, d], R_tr[:, d])`，`apply_cuts(Tp[:, d], cuts)`；
     - `quant_T`：`cuts = quantile_cuts(Ti[:, d], R_tr[:, d])`，`apply_cuts(Tp[:, d], cuts)`（只作附录中规则对应比较，不参加选型）。
  5. 返回 `{'test_idx': te, 'R_te', 'I_te', 'sigma', 'round_T', 'qwk_T', 'quant_T'}`。
  - 函数内不得读取 `Z[te]` 以外的测试行信息，且 `Z[te]` 只能出现在步骤 3。
- `select_c1_map(R_te, grades: dict) -> tuple[str, dict]`：`grades` 为 `{'round_T': (5, 250, 50), 'qwk_T': (5, 250, 50)}`。对每个候选，逐次重复、逐维计算 `qwk_score(R_te[r, :, d], g[r, :, d])`，对有定义的维度取平均，再对 5 次重复取平均，返回得分最高者的名称与得分字典；平局取 `round_T`。选型只用 `R_te`，不得用 $G$。
- `c2_fold(xbar, Z, train_idx, test_idx, oof_z, inner_z) -> dict`：
  1. `tr`、`te` 排序；对每个维度 `d`，`a, b = np.polyfit(Z[tr, d], xbar[tr, d], 1)`（训练折内用真实 $z$ 拟合，不用预测值）。
  2. `mu_te = a * oof_z + b`，`mu_inner = a * inner_z + b`（逐列）。
  3. 对每个维度调用 W3 的 `apply_rules(mu_te[:, d], mu_inner[:, d], xbar[tr, d])`。
  4. 返回 `{'test_idx': te, 'mu': mu_te, 'inner_mu': mu_inner, 'coef': (50, 2), 'p': (n_te, 50, 7), 'grades': {规则: (n_te, 50)}}`，规则取 `C2_RULES`。
- 删除旧的 `fit_predict_c1`、`fit_predict_c2`。

## 任务 3：`code/scripts/solve_q1_ordinal.py`（新写）

- 脚本最前面（`import numpy` 之前）设置三个线程环境变量为 1。
- 参数 `--smoke`（读写 `SMOKE_DIR`，只处理 `q1_main_oof.npz` 中已有的外层折）、`--workers`（默认 8，不得超过 8）。
- 流程：`require_sklearn()`、`ensure_dirs()`；读 `q1_data.npz`（`xbar`、`G`、`date_group`）、`q1_main_oof.npz`（`chosen_params` JSON、`fold_id`）、`q1_scores.npz`（`grade_median`）；`load_q1()` 取 `X`、`style`；`outer_splits(date_group, style)`，断言每次重复每折的测试行与 `fold_id` 一致。
- 单元 `(r, k)`，共 25 个；对每个单元，`chosen = {组名: chosen_params[f'{r}_{k}_{组名}'] for 组名 in DIM_GROUPS}`，调用 `k2_fold`；用 `joblib.Parallel(n_jobs=workers)` 并行；每个单元写 `CHUNK_DIR/ordinal/r{r}_k{k}.npz`（键 `test_idx`、`p`、`fallback`），已存在则读取。
- 合并：`p_k2` 形状 `(5, 250, 50, 7)`；`fallback` 形状 `(5, 5, 50, 6)`（r, k, 维度, 阈值）；合并前断言每次重复每款啤酒恰好写入一次。
- 输出 `PROCESSED_DIR/q1_ordinal.npz`，键：`p_k2`、`grade_k2_median = dist_median(p_k2)`、`fallback`、`checks`（JSON 列表）、`wall_time_s`、`seed`、`meta`。
- 任一检查项不通过时仍写出 npz，随后以非零退出码结束并在终端列出失败项。

## 任务 4：`code/scripts/solve_q1_twostage.py`（新写）

- 脚本最前面设置三个线程环境变量为 1；参数同上。
- 阶段 A（z 模型的嵌套 CV，耗时）：读 `Z = load_q1().Z`；对 25 个单元调用 W2 的 `fit_outer_fold(X_raw, Z.to_numpy(), dims, DIM_GROUPS, date_group, style, train_idx, test_idx, inner_seed=SEED + 100 + r)`（`Y` 取 `Z`，选择标准自动变为对 $z$ 的 RMSE/SD；调用方式与 `solve_q1_main.py` 相同，参数名以 W2 的实际签名为准）；每个单元写 `CHUNK_DIR/twostage_z/r{r}_k{k}.npz`（键 `train_idx`、`test_idx`、`oof`、`inner`、`chosen`、`scores`，后两个为 JSON 字符串），已存在则读取；用 `joblib.Parallel` 并行。
- 阶段 B（快，串行）：`panels = infer_panels(Z_df, k=3)`；对每个单元调用 `c1_fold` 与 `c2_fold`，写入合并数组。合并后：
  - `grade_c1_round`、`grade_c1_qwk`、`grade_c1_quant`、`R_te`、`I_te`（5, 250, 50）；
  - `select_c1_map` 选出 `c1_selected`（`'round_T'` 或 `'qwk_T'`）与 `c1_select_scores`（JSON）；`grade_c1_sel` 取所选映射的等级；
  - C2：`oof_c2`（5, 250, 50）、`inner_c2`（5, 5, 250, 50，非训练行为 NaN）、`coef_c2`（5, 5, 50, 2）、`p_c2`（5, 250, 50, 7）、`grade_c2_<规则>`（5, 250, 50），规则取 `C2_RULES` 全部六项；
  - z 模型：`oof_z`（5, 250, 50）、`inner_z`（5, 5, 250, 50）、`chosen_params_z`（JSON，键 `r_k_组名`）、`sigma`（5, 5, 50）；
  - `panels`（250）、`checks`（JSON 列表）、`wall_time_s`、`seed`、`meta`。
- 输出 `PROCESSED_DIR/q1_twostage.npz`。任一检查项不通过时仍写出 npz，随后以非零退出码结束并在终端列出失败项。
- 不读取原始评分，不读取 `xbar` 以外的评分量；`xbar` 与 `G` 只用于 C2 的校准（训练行）和 `checks` 的评价。

## 任务 5：测试

`code/tests/test_q1_ordinal.py`：
- `cumulative_to_dist([[0.9, 0.5, 0.6, 0.2, 0.1, 0.0]])` = `[[0.1, 0.4, 0.0, 0.3, 0.1, 0.1, 0.0]]`（`atol=1e-12`），行和为 1，`dist_median` 为 1。
- 全部训练等级为 0 时（`G_tr = np.zeros(40, int)`），`fit_predict_k2` 的 6 个标志全为 True，`p` 的每行等于 `[1, 0, 0, 0, 0, 0, 0]`。
- 人造数据：`X_tr` 为 150×5 的标准正态（种子 0），`G_tr = np.clip(np.round(2 + 1.5 * X_tr[:, 0]), 0, 6).astype(int)`，`X_te` 为 50×5；每行 `p` 和为 1（`atol=1e-12`）、所有元素 ≥ 0、`p` 的期望等级与 `X_te[:, 0]` 的 Spearman 相关大于 0.5。
- 无泄漏：真实数据重复 0 的折 0，`dims=['alcohol', 'body']`，`dim_groups={'Basic': ['alcohol', 'body']}`，`chosen` 取 `{'Basic': {'max_depth': 2, 'min_samples_leaf': 10, 'learning_rate': 0.05, 'l2_regularization': 0.0, 'max_iter': 100, 'mono': False}}`：把 `xbar` 的测试行换成 `np.random.default_rng(1).uniform(0, 6)` 后 `p` 不变；训练行的 `xbar` 加 1 后 `p` 必须改变。

`code/tests/test_q1_twostage.py`：
- `group_zeros`：`Z = [[0.1, 0.3], [0.1, 0.3], [0.5, 0.9], [0.2, 0.4]]`，`dims = ['d0', 'F_malt_all']`，`panels = [0, 0, 0, 1]`，`idx = [0, 1, 2, 3]`：第 0 列前三行为 0.1，第 3 行为 NaN（品评团只有 1 个成员）；`F_malt_all` 列全为 NaN。`idx = [0, 2]` 时全为 NaN（最小值只出现一次）。`idx = [0, 1]` 时第 0 列前两行为 0.1，第 2 行为 NaN（`idx` 之外的行保持 NaN）。
- `local_scale`：两个品评团的零点为 −0.4 和 −0.6，各 2 个成员，`m=3` 时 $r=0.5$、$\sigma=1.2$（`atol=1e-12`）；零点为正（$r<0$）时返回 NaN；没有零点时返回 NaN。
- `mixed_reference`：`z = [[1.0], [0.0]]`，`zb = [[0.0], [nan]]`，`sigma = [1.2]`，`lo = [-1.0]`，`hi = [2.0]`：`R = [[1], [2]]`，`use = [[True], [False]]`，且不产生 NaN 转整数的警告（用 `warnings.simplefilter('error')` 包住调用）。
- `c1_fold` 无泄漏：真实数据重复 0 的折 0，`oof_z`、`inner_z` 用任意固定随机数组（种子 0）代替；把 `Z` 的测试行换成随机数后，`round_T`、`qwk_T`、`quant_T`、`sigma` 不变，`R_te` 允许改变；训练行的 `Z` 改变后 `sigma` 或 `round_T` 必须改变。
- 品评团不跨折：真实数据 `infer_panels(Z, k=3)` 的 41 个多啤酒团，在 `outer_splits` 的每次重复中各自完全落在同一个测试折内。
- `select_c1_map`：构造 `R_te` 与两个候选等级，使 `qwk_T` 的得分更高时选 `qwk_T`；两者得分相同时选 `round_T`。
- `c2_fold`：`oof_z`、`inner_z` 取与 `Z` 同尺度的随机数；`grades` 各规则取值在 0..6、`p` 每行和为 1（`atol=1e-12`）；`Z[te]` 换成随机数后 `coef` 不变。
