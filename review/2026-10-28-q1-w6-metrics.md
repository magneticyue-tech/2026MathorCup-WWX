## 固定口径（先读懂再写代码）

- 所有等级指标都在 5 次重复各自的折外等级上分别计算，再对 5 次重复取平均；每次重复的 12,500 个单元权重相同。交付值 `G_hat`（5 次先平均 `p` 再取中位数）单独报告，不与对照比较。
- 主模型与全部连续对照使用同一规则作比较：预测分布中位数（键 `median`）。其余规则只在规则比较中使用。
- 模型键与产物键的对应：

| 模型键 | 等级数组 | 概率 | 连续预测 |
|---|---|---|---|
| `main` | `q1_scores.npz` 的 `grade_<规则>`，规则取 `const`、`round`、`median`、`quant`、`qwk_cut`、`median_knn` | `p`（规则 `median`）、`p_knn`（规则 `median_knn`） | `q1_main_oof.npz` 的 `oof_mu` |
| `b0`、`b1`、`lin10`、`enet`、`rf`、`chemstyle` | `q1_baselines.npz` 的 `grade_<键>_<规则>`，规则同上 | `p_<键>` | `oof_<键>` |
| `k2` | `q1_ordinal.npz` 的 `grade_k2_median`，只有规则 `median` | `p_k2` | 无 |
| `c1` | `q1_twostage.npz` 的 `grade_c1_sel`（规则键 `sel`）、`grade_c1_round`、`grade_c1_qwk`、`grade_c1_quant`（规则键 `round`、`qwk`、`quant`） | 无 | 无（$\hat z$ 不在 x̄ 尺度） |
| `c2` | `q1_twostage.npz` 的 `grade_c2_<规则>` | `p_c2` | `oof_c2` |

- RPS 与对数损失只对规则 `median` 填写（`main.median_knn` 用 `p_knn`）；其余规则和 `c1` 填 null，并在同一条目写 `rps_reason`、`logloss_reason`。
- 连续指标（MAE、R²、Spearman、RMSE/SD）对 x̄，只对有连续预测的模型填写。

## 任务 1：`metrics.py`（重写，删除旧函数）

常量：`N_BOOT = 2000`；`EPS_LOG = 0.01`；`CTRL_MODELS = ('b0', 'b1', 'lin10', 'enet', 'rf', 'chemstyle')`；`ALL_RULES = ('const', 'round', 'median', 'quant', 'qwk_cut', 'median_knn')`；`PAIR_STATS = ('mae', 'exact', 'within1', 'qwk', 'rps', 'logloss', 'cont_mae')`。

混淆矩阵与等级指标（`G` 为 (250, 50) int，`Gh` 为 (R, 250, 50) int，`w` 为 (250,) 的非负权重，默认全 1）：

- `conf_weighted(G, Gh, w=None) -> ndarray (R, 50, 7, 7)`：单次 `np.bincount` 完成。下标 `((r * 50 + d) * 49) + 7 * G[b, d] + Gh[r, b, d]`，权重为 `w[b]`，`minlength = R * 50 * 49`，再 reshape。
- `mae_dim(conf)`、`exact_dim(conf)`、`within1_dim(conf)` -> (R, 50)：分别为 `sum(conf * |i - j|) / sum(conf)`、对角线占比、`|i - j| <= 1` 的占比。
- `qwk_dim(conf) -> (R, 50)`：`o = conf`，`e = np.outer(o.sum(1), o.sum(0)) / o.sum()`，`W[i, j] = (i - j) ** 2`；分母 `(W * e).sum()` 为 0 时为 NaN，否则 `1 - (W * o).sum() / (W * e).sum()`。
- `grade_mae(G, Gh)`、`exact(G, Gh)`、`within1(G, Gh)`：上面三个函数在 `w=None` 下对 (R, 50) 取平均的标量。
- `qwk_by_dim(G, Gh) -> (R, 50)`：`qwk_dim(conf_weighted(G, Gh))`。
- `mean_qwk(q) -> tuple[float, int]`：返回 `np.nanmean(q)` 与 NaN 单元个数（单元为「重复 × 维度」）。全 NaN 时返回 `(nan, q.size)`。
- `qwk_pair(qa, qb) -> tuple[float, float, int]`：`mask = ~isnan(qa) & ~isnan(qb)`，返回两方在 `mask` 上的均值与被剔除的单元个数。方法论 §5.2：配对平均中对两种方案同时剔除。
- `confusion_pooled(G, Gh) -> ndarray (7, 7)`：对 50 维求和、对 R 取平均，行为真实等级，列为预测等级。
- `recall_by_class(cm) -> ndarray (7,)`：对角线除以行和，行和为 0 的等级为 NaN。
- `balanced_accuracy(cm) -> float`：`np.nanmean(recall_by_class(cm))`，即只对真值中出现的等级取平均。
- `share_high(Gh) -> float`：`(Gh >= 5).mean()`。
- `grade_freq(g) -> ndarray (7,)`：各等级占比。

预测分布指标（`p` 为 (R, 250, 50, 7)）：

- `rps_cells(p, G) -> (R, 250, 50)`：`F = np.cumsum(p, -1)[..., :6]`，`O = (G[None, :, :, None] <= np.arange(6))`，`((F - O) ** 2).sum(-1)`。
- `logloss_cells(p, G, eps=EPS_LOG) -> (R, 250, 50)`：`pp = (1 - eps) * p + eps / 7`，`-np.log(np.take_along_axis(pp, G[None, ..., None] 广播后, -1)[..., 0])`。
- `climatology_p(G, fold_id) -> (R, 250, 50, 7)`：对每个重复 `r`、折 `k`，训练行为 `fold_id[r] != k`，测试行的 `p` 为训练行等级 `G[训练行, d]` 的频率；只用训练行等级。

连续指标（`mu` 为 (R, 250, 50)，`xbar` 为 (250, 50)）：

- `cont_abs_cells(mu, xbar) -> (R, 250, 50)`：`|mu - xbar|`。
- `r2_by_dim(mu, xbar) -> (R, 50)`：`1 - sum((xbar - mu) ** 2) / sum((xbar - xbar.mean(0)) ** 2)`，对 250 款求和。
- `rmse_over_sd(mu, xbar) -> (R, 50)`：`sqrt(mean((xbar - mu) ** 2)) / np.std(xbar, axis=0, ddof=0)`。
- `spearman_by_dim(mu, xbar) -> (R, 50)`：`scipy.stats.spearmanr`；预测为常数时为 NaN（B0 与 B1 在个别重复可能出现），不得用 0 代替。

比较与分组：

- `wins_by_dim(G, Gh_a, Gh_b) -> int`：先对每个维度的逐单元绝对误差在 5 次重复上取平均，再数 `a` 严格低于 `b` 的维度个数。`wins_by_dim_cont(mu_a, mu_b, xbar) -> int` 同理，用连续绝对误差。
- `coverage(G, lo, hi) -> tuple[float, float]`：`G` 落在 `[lo, hi]` 内的占比与 `(hi - lo).mean()`；`lo`、`hi` 为 (250, 50)。
- `subset_report(G, Gh, idx) -> dict`：`idx` 为维度下标数组；返回 `n_dims`、`mae`、`exact`、`qwk`（`mean_qwk` 的均值）、`qwk_undefined`。用于 `ZERO_HEAVY_DIMS`（22 个）与其余 28 个维度的分开报告。
- `reference_error(R, I, G) -> dict`：C1 的混合参照 `R` 与真值 `G` 的差距。`R`、`I` 为 (5, 250, 50)；对 `all`、`A`（`I` 为真）、`L`（`I` 为假）三类单元分别给出 `cells_per_rep`（单元数除以 5）、`exact`、`within1`、`mae`、`bias = mean(R - G)`，对 5 次重复合并后计算。

聚类 bootstrap（整组重抽样，权重法）：

- `bootstrap_weights(groups, n_boot=N_BOOT, seed=SEED) -> ndarray (n_boot, 250)`：`rng = np.random.default_rng(seed)`；对每次抽样 `draw = rng.integers(0, n_groups, n_groups)`，`counts = np.bincount(draw, minlength=n_groups)`，该次权重为 `counts[group_index]`，其中 `group_index` 是把 `groups` 的取值映射为 0..n_groups-1 后的每款啤酒的组下标。所有比较共用同一个权重矩阵，使比较之间的抽样一致。
- `cluster_bootstrap(stat_fn, W) -> tuple[ndarray, ndarray, ndarray]`：`stat_fn(w)` 返回长度 k 的向量；`point = stat_fn(np.ones(250))`；`boot = np.array([stat_fn(w) for w in W])`；返回 `point`、`np.percentile(boot, 2.5, axis=0)`、`np.percentile(boot, 97.5, axis=0)`。每次重抽样都重新计算统计量，QWK 逐维重算后再平均，不得对点估计的 QWK 做平移。
- `pair_stat_fn(G, a, b, xbar=None) -> callable`：`a`、`b` 为字典，键 `g`（(R, 250, 50) 等级，必须有），`p`（(R, 250, 50, 7)，可无），`mu`（(R, 250, 50)，可无）。返回的 `stat_fn(w)` 给出长度 7 的向量，顺序为 `PAIR_STATS`，每项均为 `a` 减 `b`：
  - `mae`、`exact`、`within1`：由 `conf_weighted(G, g, w)` 得到的 (R, 50) 逐维值取平均；
  - `qwk`：`qwk_pair(qwk_dim(conf_a), qwk_dim(conf_b))` 的两个均值之差（每次重抽样内重新确定被剔除的单元）；
  - `rps`、`logloss`：`(cells * w[None, :, None]).sum() / (w.sum() * R * 50)`，两方都有 `p` 时才算，否则为 NaN；
  - `cont_mae`：两方都有 `mu` 与 `xbar` 时，`cont_abs_cells` 的同样加权平均之差，否则为 NaN。
  - 为快，`p`、`mu` 对应的逐单元量在闭包外一次算好。

删除旧函数 `exact_match`、`log_loss_score`、`split_report`、`cluster_bootstrap(a, b, groups, ...)`。

## 任务 3：测试 `code/tests/test_q1_metrics.py`

手算与一致性用例（逐项断言）：

- `grade_mae`：`G` 为 250×50 的全 1，`Gh` 全 3，MAE = 2.0；`exact` = 0；`within1` = 0。
- `conf_weighted`：任意一组等级上每个 `(r, d)` 的混淆矩阵总和等于 250；`mae_dim(conf).mean()` 与 `np.abs(G - Gh).mean()` 在 1e-12 内相等；`qwk_dim` 与 `sklearn.metrics.cohen_kappa_score(weights='quadratic', labels=range(7))` 在 20 组随机整数数组（种子 0）上相差不超过 1e-10；某维 `G` 与 `Gh` 全为同一等级时，`qwk_dim` 为 NaN。
- `qwk_pair`：`qa = [0.2, nan, 0.4]`、`qb = [0.1, 0.3, nan]` 时返回 `(0.2, 0.1, 2)`。
- `balanced_accuracy`：`cm` 的第 5、6 行全为 0 时，只对第 0–4 行取平均；手算 `cm = diag([2, 2, 2, 2, 2, 0, 0])` 加上第 0 行有一个误判到第 1 列（第 0 行为 `[1, 1, 0, 0, 0, 0, 0]`），召回率为 `[0.5, 1, 1, 1, 1, nan, nan]`，平衡准确率 0.9。
- `rps_cells`：`p = [0, 0.5, 0.5, 0, 0, 0, 0]`，`G = 1` 时为 0.25；`G = 2` 时为 0.25；`G = 0` 时为 1.25。
- `logloss_cells`：`p = [1, 0, 0, 0, 0, 0, 0]`，`G = 0` 时为 `-log(0.99 + 0.01 / 7)`；`G = 1` 时为 `-log(0.01 / 7)`（约 6.5511）。
- `climatology_p`：构造 `fold_id` 与 `G`，验证测试行的分布只由训练行等级决定：改变测试行的 `G` 后结果不变。
- `r2_by_dim`：`mu = xbar` 时为 1；`mu` 为 `xbar` 的列均值常数时为 0。
- `spearman_by_dim`：预测为常数的维度返回 NaN。
- `wins_by_dim`：构造 3 个维度，`a` 在 2 个维度上误差更低、1 个维度持平，返回 2。
- `coverage`：手算 4 个单元的覆盖率与宽度。
- `reference_error`：构造 `R = G + 1` 且 `I` 一半为真，`bias = 1`、`mae = 1`、`exact = 0`。
- 权重 bootstrap 与显式重抽样一致：`groups` 为 5 个组、每组 4 款共 20 款的小例子（`G` 为随机等级，种子 0）；取 `bootstrap_weights` 的第 0 行，用 `np.repeat(np.arange(20), w)` 得到重抽样下标，直接对重抽样后的数组算 MAE、完全一致率和逐维 QWK，与 `pair_stat_fn` 在该权重下给出的值在 1e-12 内相等（需要把 250 的写死改为由输入长度决定，`bootstrap_weights` 与 `pair_stat_fn` 都不得写死 250、50）。
- `cluster_bootstrap`：同一种子两次调用结果完全相同；`point` 等于 `stat_fn(全 1)`；`lo <= point <= hi` 在 `a` 与 `b` 相同时恒有 `lo = hi = 0`。
- 无泄漏：`pair_stat_fn` 的签名只含 `G, a, b, xbar`，不读取任何拟合量（断言参数个数）。
