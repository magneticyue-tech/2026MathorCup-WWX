## 问题

- 实现方法论 §3.2 的可选实验：把酯类与硫化合物两个类别的气味活度值（OAV）之和加入特征，检验是否降低内层 RMSE/SD、是否改善等级 MAE。
- 本工单可选，不阻塞 W6–W8；W2 通过，且 W6、W7 的函数可用后再做。旧工单把酚类也列为一类，方法论已改为只有两类（带阈值的酚类只有 4VG，求和没有新信息）。
- 依赖：W1（`ChemNAEncoder`、`DIMS`、`DIM_GROUPS`、`load_q1`）；W2（`inner_splits`、`outer_splits`、`make_hgb`、`monotone_cst`、`q1_main_oof.npz` 的 `chosen_params`、`inner_mu`、`oof_mu`、`fold_id`）；W3（`apply_rules`、`dist_median`、`dist_interval`、`q1_scores.npz`）；W6（`bootstrap_weights`、`cluster_bootstrap`、`pair_stat_fn`）；W7（`unit_grades`、`merge_arm`、`delivered`、`changed_share`）。
- 只创建：`code/src/q1/oav.py`、`code/scripts/solve_q1_oav.py`、`code/tests/test_q1_oav.py`。不修改 W7 的 `sensitivity.py`。
- 运行环境与通用约定见本工单末尾「通用约定」。

## 固定规则

- 类别名单（字面量常量 `OAV_CLASSES`，列名与 `data/raw/1.csv` 一致）：
  - `esters`（13 个）：`ethyl_2.methyl_butyrate`、`ethyl_acetate`、`ethyl_decanoate`、`ethyl_hexanoate`、`ethyl_isovalerate`、`ethyl_octanoate`、`ethyl_propionate`、`isobutyl_acetate`、`isopentyl_acetate`、`octyl_acetate`、`phenethyl_acetate`、`ethyl.isobutyrate`、`ethyl.butyrate`；
  - `sulfur`（4 个）：`DES`、`DMS`、`H2S`、`CS2`。
  - 不纳入：`ethyl.nicotinate`、`SO2.mg.L.`、`sulfur_sum`、`esters_sum`、4VG（理由见方法论 §3.2）。
- 阈值：读 `experimentalCode/results/data_audit/chemical_dictionary.csv`（`encoding='utf-8-sig'`，Q2 已采用同一做法）的 `csv1_field`、`threshold_mean`、`unit`、`transform_interpretation`、`calibrated`。路径常量 `DICTIONARY_CSV = ROOT / 'experimentalCode' / 'results' / 'data_audit' / 'chemical_dictionary.csv'`。
- 浓度：`transform_interpretation` 以 `log10` 开头的列取 `10 ** x`，其余列取原值；该列的浓度与阈值使用字典同一行的同一单位。
- OAV 和：`oav_<类别> = sum(conc_c / threshold_c)`，在类别内求和；输入是已经按训练折列均值填充后的化学表，因此没有 NaN；阈值是常量，不依赖任何数据，不存在折间泄漏。信号下限单元按其数值参与计算，不另作处理。
- 实验臂：特征为编码后的 231 列加 `oav_esters`、`oav_sulfur`，共 233 列；超参数沿用主运行在每个外层折、每个维度组选定的值（含 `mono`）；单调约束对两个新列为 0；外层划分、内层种子、残差池与切点规则同 W7。
- 比较规则取预测分布中位数，对 G 评价。

## 任务 1：`oav.py`

- `OAV_CLASSES`、`DICTIONARY_CSV`（见上）。
- `load_thresholds(path=DICTIONARY_CSV) -> dict[str, tuple[float, bool]]`：键为 `csv1_field`，值为 `(threshold_mean, is_log10)`；只返回 `threshold_mean` 非空的行；断言个数为 43，断言阈值均大于 0。
- `concentration(x, is_log10) -> ndarray`：`10 ** x` 或 `x`。
- `oav_class_sums(X_enc, thresholds, classes=OAV_CLASSES) -> DataFrame`：`X_enc` 为编码后的 DataFrame；返回两列 `oav_esters`、`oav_sulfur`，行索引同 `X_enc`；类别内任一化合物不在 `X_enc` 列中或不在 `thresholds` 中即 `raise KeyError`；`X_enc` 含 NaN 即 `raise ValueError`。
- `fit_fold_oav(X_raw, Y, dims, dim_groups, groups, style, train_idx, test_idx, inner_seed, chosen, thresholds, add_oav=True) -> dict`：与 W7 的 `fit_fold_fixed` 相同的内外层结构（`tr`、`te` 排序；内层每个折在内层训练行上拟合 `ChemNAEncoder('col_mean')`，编码训练与验证行后，若 `add_oav` 则把 `oav_class_sums` 的两列拼到后面；外层同理），`monotone_cst` 的 `names` 含新列名；返回 `{'train_idx', 'test_idx', 'oof', 'inner'}`。`add_oav=False` 时结果必须与 W7 的恒等臂相同。函数内不得读取 `Y[te]`。
- `inner_ratio(inner, y, train_idx) -> ndarray (50,)`：对训练行（排序后）的内层折外预测 `inner` 与 `y[train_idx]`，按维度计算 `sqrt(mean((y - inner) ** 2)) / std(y, ddof=0)`；分母为零时该维返回 NaN，原因记为目标在该折训练集恒定，不把无定义的比值写成 0。主设定与实验臂都用该函数从各自的内层折外预测计算，二者口径一致。
- `exceed_count(X_raw, thresholds) -> int`：原始化学表中，在至少一款啤酒上浓度超过阈值的带阈值化合物个数（NaN 不计）。

## 任务 2：`code/scripts/solve_q1_oav.py`

- 脚本最前面（`import numpy` 之前）设置三个线程环境变量为 1。参数：`--smoke`（只跑重复 0 的折 0、1，输出写入 `SMOKE_DIR`，只做结构类检查）、`--workers`（默认 8，不得超过 8）。
- 流程：`require_sklearn()`、`ensure_dirs()`；读 `q1_data.npz`（`xbar`、`G`、`date_group`）、`q1_main_oof.npz`（`chosen_params`、`inner_mu`、`oof_mu`、`fold_id`）、`q1_scores.npz`（`grade_median`、`p`、`G_hat`）；`load_q1()` 取 `X`、`style`；`outer_splits(date_group, style)`，断言每折测试行与 `fold_id` 一致。
- 单元为 `(r, k)`，共 25 个，加两个恒等检查单元（重复 0 的折 0、1，`add_oav=False`）。用 `joblib.Parallel(n_jobs=workers)` 并行；每个单元写 `CHUNK_DIR/oav/r{r}_k{k}.npz`（键 `train_idx`、`test_idx`、`oof`、`inner`），已存在则读取。
- 合并后：`unit_grades` 与 `merge_arm`（W7）得到该臂的 `oof_mu`、`inner_mu`、`grade_median`、`p`；`delivered` 得 `G_hat`、`lo`、`hi`。
- 比较（只生成一次 `bootstrap_weights(date_group)`）：`cluster_bootstrap(pair_stat_fn(G, arm, main, xbar), W)`，七项统计量的 `point`、`lo`、`hi`；`wins_a`；`changed_delivered`、`changed_median`；零分为主与其余维度的等级 MAE 之差。
- 内层 RMSE/SD：对 25 个外层折，计算主设定与实验臂的 `inner_ratio`（主设定的内层折外预测取 `q1_main_oof.npz` 的 `inner_mu[r, k, 训练行]`）；记录每折每维的差（臂减主设定）、每折有效维度的等权平均差及有效维度数。两臂在同一维度上分母相同；分母为零的维度在两臂均剔除。整折无有效维度时不计为改善并记录原因。`inner_reduced_folds` 为平均差严格小于 0 的折数，13/25 是预定的简单多数描述阈值，不是 25 个独立试验的显著性检验（方法论 §3.2）。
- 记录判定（只记录，不改任何模型）：
  - `inner_reduced = inner_reduced_folds >= 13`；
  - `mae_ci_below_zero`：`mae` 的 `hi < 0`；
  - `review_candidate = inner_reduced and mae_ci_below_zero`；只表示触发复核，不表示采用实验臂。
  - 为 True 时在回报中指出并自动开 `review/` 线程讨论 OAV 特征假设；主设定不切换，线程不阻塞 W8（方法论 §3.2）。
- 输出 `PROCESSED_DIR/q1_oav.npz`：`oof_mu`（5, 250, 50）、`inner_mu`（5, 5, 250, 50）、`grade_median`、`p_final`、`G_hat`、`inner_ratio_arm`（5, 5, 50）、`inner_ratio_main`（5, 5, 50）、`oav_esters`、`oav_sulfur`（250，全数据编码后的两个和，仅供描述，不用于拟合）、`checks`、`wall_time_s`、`seed`、`meta`；另写 `q1_oav.json`：键 `classes`（实际使用的名单与阈值，含单位）、`pair`（`point`、`lo`、`hi`、`wins_a`）、`changed_delivered`、`inner_valid_dims`（5×5 的有效维度数）、`inner_reduced_folds`、`inner_reduced`、`mae_ci_below_zero`、`review_candidate`、`exceed_count`、`checks`、`seed`、`meta`。JSON 中无定义数值写 `null` 并附原因字符串；`json.dump(..., allow_nan=False)`。
- 任一结构类检查项不通过时仍写出文件，随后以非零退出码结束并在终端列出失败项。

## 任务 3：`code/tests/test_q1_oav.py`

- `load_thresholds`：真实字典上个数为 43；`DES`、`ethyl.butyrate` 在其中；`ethyl.butyrate` 不是 log10 列，`DES` 是 log10 列。
- `oav_class_sums`：人造表，酯类两个化合物浓度 2、3，阈值 1、3，硫化合物一个化合物 `x=1`（log10 列，浓度 10）阈值 5：`oav_esters = 3.0`、`oav_sulfur = 2.0`（`atol=1e-12`）；缺列抛 `KeyError`；含 NaN 抛 `ValueError`。
- `OAV_CLASSES`：酯类 13 个、硫化合物 4 个、互不相交；全部列名在 `data/raw/1.csv` 与阈值字典中；不含 `ethyl.nicotinate`、`SO2.mg.L.`。
- `fit_fold_oav` 恒等：真实数据重复 0 的折 0，`dim_groups={'Basic': ['alcohol', 'body']}`，`add_oav=False` 的 `oof`、`inner` 与 W7 的 `fit_fold_fixed` 在 `atol=1e-10` 内相等。
- `fit_fold_oav` 无泄漏：把 `Y` 的测试行换成 `np.random.default_rng(1).uniform(0, 6)` 后，`oof`、`inner` 不变；训练行加 1 后 `oof` 必须改变；`add_oav=True` 与 `False` 的 `oof` 不完全相同。
- `inner_ratio`：预测等于真值时为 0；预测为训练行均值常数时为 1；训练行目标恒定时返回 NaN，汇总时剔除并记录有效维度数。
