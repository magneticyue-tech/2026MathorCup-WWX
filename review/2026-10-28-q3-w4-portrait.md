## 问题

Q3 缺少 22 个风格的感官画像、风味指纹和画像验证（方法论 §4.1、§4.3、§6.3）的实现。
本工单把生成器输出接到问题 1 模型，产出 `q3_portraits.npz` 与 `q3_portrait_val.npz`。

## 背景 / 复现

读方法论 §1、§2.1、§4、§6.3：连续画像为 Q1 原始评分均值目标下的 0–6 分 $\hat\mu_d$；等级分布由 `predictive_dist(μ̂_d, final_resid_d)` 给出；主等级取 `dist_median`，替代映射取 `apply_cuts(μ̂_d, final_qcuts_d)`；观测对照为 `q1_data.npz` 中的 $\bar x$，该文件由 `data/raw/raw_sensory_data_anonymized.csv` 整理得到。附件 4 的标准化 $z$ 不作为画像目标或观测对照。参考实现为预检查 4、6，第 331–351 行与第 373–419 行，其中感官模型是固定超参数的代理，不得沿用。
问题 1 的 Python 包路径与导入方式以 `code/scripts/solve_q1_main.py` 为准；Q3 脚本用同一方式把 `code/src` 加入 `sys.path`，从 `q1.discretize` 导入 `predictive_dist`、`dist_median`、`dist_interval`、`apply_cuts`。

## 文件与函数

### T1 `q1_bridge.py`

- `Q1Bundle`：`models`（50 个已拟合模型，按 `DIMS` 顺序）、`encoder`（拟合后的 `ChemNAEncoder(col_mean)`）、`final_resid`（50 个残差池）、`final_qcuts`（50×6）、`dims`、`chem_cols`。
- `load_q1_bundle() -> Q1Bundle`：从 `q1_models/` 与 `q1_scores.npz` 读取；文件缺失抛 `FileNotFoundError`。
- `predict_mu(bundle, X231: DataFrame) -> ndarray[n,50]`：列按 `chem_cols` 排序，经 `encoder.transform` 后逐维预测；Q1 的 `transform` 若返回缺失指示列，按 Q1 `model.py` 实际的特征组装方式处理，并写进回报。
- `grade_dist(bundle, mu) -> ndarray[n,50,7]`、`grade_median(bundle, mu) -> ndarray[n,50] int`、`grade_quant(bundle, mu) -> ndarray[n,50] int`。
- `fit_fold_bundle(X231, xbar, G, train_idx, outer_rep, outer_fold) -> Q1Bundle`：画像验证用。超参数取 `q1_main_oof.npz` 的 `chosen_params`（该外层折、各维度组），不重新选参；在 `train_idx` 上拟合；残差池取 `inner_mu` 中该外层折训练啤酒的内层折外预测与 xbar 之差；切点由该折训练啤酒的内层预测与 G 按 `quantile_cuts` 计算。`train_idx` 必须与 `q1_main_oof.npz` 中该重复、该折的训练集一致，断言 `fold_id`。

### T2 `portrait.py`

- `assemble_input(gen, comp, u, internal_std_value) -> DataFrame[n,231]`：225 个生成列取 `gen.mg.inverse(u)`；综合指标取 `comp.to_original(comp.predict_latent(u))`；内标取 `internal_std_value`（训练啤酒中位数）；列序为 `chem_cols`。
- `portrait_samples(gen, comp, bundle, style, n, rng) -> dict`：抽 `sample_latent`，组装输入，得 `mu`（n×50）、`G`（n×50，`grade_median`）、`p`（n×50×7，`grade_dist`）。
- `summarize(mu, G, p) -> dict`：`mu_q10`、`mu_q50`、`mu_q90`（50）；`pi`（50×7，G 的各等级频率）；`mode`（50，众数，并列取较小）；`pi_tilde`（50×7，p 对样本平均）。
- `chem_fingerprint(gen, style, n_boot=1000, seed) -> dict`：δ_sj = (mu_sj − ū_j) / sqrt(C_jj)；bootstrap 对该风格的训练啤酒有放回抽样，重算 mu_s（n_s·均值 + κ·ū）/（n_s + κ），C、Marg、ū 不变，取 δ 的 5% 与 95% 分位；区间含 0 的项标 `ci_covers_zero`。
- `fingerprint_table(delta, delta_lo, delta_hi, style, spec) -> DataFrame`：|δ| 最大的 10 项；同一 Q2 模块只列 |δ| 最大的成员，其余成员写入 `same_module`；每项附字典的 `origin_paper`、`off_flavors`、`aging`（空值保留为缺失）与该风格的下限比例（`np.isclose(x_filled, 列最小值)` 的比例）。
- `sensory_fingerprint(summary_by_style, samples_by_style) -> DataFrame`：合并画像取 22 个风格各 1,000 个样本的并集；每个风格每个维度的偏离 = (mu_q50_s − 合并中位数) / 合并标准差；barnyard 行标注 同 stale_hops；Q1 逐维未胜过 B1 的维度标 `weak_dim`。

### T3 `portrait_val.py`

对 Q1 的外层划分（5 次重复 × 5 折，由 `q1_main_oof.npz` 的 `fold_id` 还原训练集与测试集），每个 (rep, fold)：
1. 在训练集上选参拟合生成器：`inner_scores`（W2）选 k、κ、结构，再 `StyleGen.fit`；内层划分按风格分层，不按日期组。训练集中只有 1 款的风格按方法论 §3.3 排除规则，不以全局均值代替。
2. `CompositeDeriver.fit` 与内标中位数都只用训练啤酒。
3. `fit_fold_bundle` 拟合该折感官模型。
4. 对训练集中有啤酒的每个风格抽 1,000 个样本，得 `mu` 的中位数、10% 与 90% 分位。
5. 对留出的同风格真实啤酒用同一感官模型预测原 231 列输入（NaN 由该折编码器按训练折列均值处理），得真实预测；再把综合指标与内标换成 `assemble_input` 的派生值预测一次，得重构预测。
6. 对训练集中没有的风格不评价，不用留出啤酒补齐。
每个 (rep, fold, style) 记录：`n_test`、`gen_med`（50）、`gen_q10`、`gen_q90`、`real_pred_med`（50）、`obs_med`（xbar 的中位数，50）、`recon_pred_med`（50）。
指标，按风格先在可评价的折间取平均：
- 生成中位数与真实预测中位数、与观测中位数在 50 维上的 Spearman 与平均绝对差；
- 真实预测中位数与观测中位数之间的同一指标，作参照；
- 生成 10%–90% 区间对留出真实预测的覆盖率（逐啤酒逐维，再平均）；
- 重构输入使真实预测改变的平均绝对量；
- 风格评价折数、可评价风格数；按样本量分组（n ≤ 5、6–15、> 15）报告。
汇总用宏平均（22 个风格等权）与按样本量加权的平均，bootstrap 以单款啤酒为单位，2,000 次，种子 0。6 项 Spearman 与平均绝对差不报告区间，只报告覆盖率与重构输入影响的区间（方法论 §6.3 修订，实现见 `review/2026-10-29-q3-w3-acceptance-a.md` 任务 C3）。

### T4 脚本

`code/scripts/solve_q3_portrait.py`：写出 `q3_portraits.npz`、`q3_fingerprint.csv`、`q3_sensory_fingerprint.csv`。
- 用 `modules_from_q2` 与 `final_config` 拟合全数据生成器，`CompositeDeriver` 与内标中位数用全部 250 款；`rng = default_rng([SEED, 风格序号])`；每个风格一个中间文件。
- npz：`styles`、`mu`（22×1000×50，float32）、`mu_q10`、`mu_q50`、`mu_q90`（22×50）、`pi`、`pi_tilde`（22×50×7）、`mode`（22×50）、`delta`、`delta_lo`、`delta_hi`（22×225）、`sens_dev`（22×50）、`seed`、`meta`。
`code/scripts/solve_q3_portrait_val.py`：写出 `q3_portrait_val.npz` 与 `q3_portrait_val.json`，25 个 (rep, fold) 为中间文件单位；`--smoke` 取 1 次重复、前 2 折。

## 验收标准

通用：`black --check code/` 与 `ruff check code/` 通过；`src/q3/` 无 `__main__`；脚本写 `seed` 与 `meta`；绘图不在本工单。

pytest（`code/tests/test_q3_portrait.py`，用小型假模型，秒级）：
- 组装路径：对 250 款真实啤酒，用 `assemble_input` 以 u_full、观测的综合指标潜变量和内标观测值组装，预测与 Q1 对原输入的预测在非 NA 行上相差不超过 1e-9（由 W5b 的源表示函数实现，本工单只测 `assemble_input` 的列序与列数 231）。
- `summarize`：`pi` 与 `pi_tilde` 每行和为 1；`mu_q10 ≤ mu_q50 ≤ mu_q90`。
- `fit_fold_bundle`：把留出啤酒的 xbar 换成随机数，选定超参数、残差池与对留出啤酒的预测都不变。
- `chem_fingerprint`：风格只有训练啤酒中的啤酒进入 bootstrap；固定种子两次结果一致。

数值核对（预运行的画像数值依赖代理模型，按方法论 §6.8 不作核对目标；以下为一致性检查）：
- `mu` 无 NaN；`pi`、`pi_tilde` 每个风格每个维度和为 1（1e-9）。
- 22 个风格全部有画像；`q3_portrait_val.json` 报告可评价风格数及各风格评价折数；Faro、Brut 等小样本风格的评价折数写入回报。
- 重构输入的影响、画像验证的各 Spearman 与覆盖率照实写入，不设通过线。
- 回报中给出：Tripel、Kriek、Lambic 的指纹前 10 项、感官偏离前 5 个维度；`weak_dim` 的维度名单。

耗时估计：画像 22 × 1,000 个样本 × 50 个模型预测很快；画像验证为 25 个外层折，每折含生成器内层选参，量级与 W2 相当，以实测回报。
